# TypeScript - Como Programar

Este repositório contém exemplos práticos e exercícios desenvolvidos em TypeScript para fins de aprendizado e estudo da linguagem.

## 📁 Estrutura do Projeto

* **`src/cap-02/`**: Exemplos práticos do Capítulo 2 (conversões, cálculos de área, etc.).
* **`src/cap-03/`**: Exemplos práticos e testes unitários de criação de objetos, construtores e classes (Account, Aluno, Conta Bancária, Produto).

## 🚀 Como Executar

### Pré-requisitos
Certifique-se de ter o [Node.js](https://nodejs.org/) instalado em sua máquina.

### Instalação de Dependências
Instale os pacotes necessários rodando o comando:
```bash
npm install
```

### Executar um Arquivo
Para executar qualquer arquivo TypeScript diretamente sem precisar compilá-lo manualmente:
```bash
npx tsx src/caminho/do/arquivo.ts
```

Ou usando o script configurado no projeto:
```bash
npm start src/caminho/do/arquivo.ts
```
